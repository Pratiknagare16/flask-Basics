About This To-Do App

This is a simple Personal To-Do List application built using Python, Flask, and Jinja2.

It helps you organize your daily tasks by tracking:

  • Task Title
  • Task Status (Pending, In Progress, Completed)
  • Task Priority (High, Medium, Low)

This project is part of Flask homework to understand:

  • Flask routing
  • Dynamic URLs
  • Template inheritance
  • Jinja2 loops, filters and conditions
